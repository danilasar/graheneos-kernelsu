# KernelSU Next для Pixel 8 / GrapheneOS — комплект выпуска

Самодостаточный комплект: отчёт, инструкции по установке и обновлению, патчи к исходникам и готовые бинарные файлы. Репозитории ядра и кеши сборки сюда намеренно не включены; их можно заново клонировать на точных ревизиях, указанных ниже.

## Ревизии для воспроизведения

```text
GrapheneOS, проверенная на устройстве: сборка 2026100201, отпечаток CP3A.260905.009, уровень исправлений безопасности 2026-09-05
Рабочее дерево ядра GrapheneOS: тег Git 2026100200, коммит 105c7cdc8e1139d83a1d8cc2dc56513e432db834 (ветка 17)
ACK common/ack: тег Git 2026100200, коммит f6f62ba75ac9dbcf802b2ca2ebce2058362a04d6
KernelSU Next: тег Git v3.4.0, коммит 1a879d6a866f80b1fa1c1009a2ffa747873cbb5e
```

Важно: проверенная сборка ОС — `2026100201`, а доступные теги исходников ядра и ACK — `2026100200`. Это различие объяснено в отчёте. Воспроизводимость относится к зафиксированным коммитам, набору патчей и переопределениям сборки, а не к произвольной свежей выгрузке исходников GrapheneOS.

## Содержимое

- `REPORT.md` — хронология, диагностика, итоговое состояние устройства.
- `INSTALL.md` — клонирование, наложение патчей, сборка, упаковка и установка.
- `UPDATE.md` — возврат к штатному состоянию, OTA-обновление GrapheneOS, пересборка, проверка и повторная установка KSU.
- `patches/` — пять патчей и порядок их применения.
- `artifacts/` — проверенный загрузочный образ, штатные образы той же сборки для отката, APK менеджера, публичный сертификат подписи модулей и `SHA256SUMS`.
- `evidence/MTE-untagged-test-result.txt` — краткая запись об успешной проверке временной загрузкой.

Проверка контрольных сумм бинарных файлов из этого каталога:

```sh
(cd artifacts && sha256sum -c SHA256SUMS)
```

Приложенный загрузочный образ предназначен только для GrapheneOS `2026100201` на Pixel 8 (`shiba`). Не используй его после OTA-обновления, на другой сборке или на другом устройстве. Загрузчик должен оставаться разблокированным. Для более новой ОС ядро нужно пересобрать из соответствующих ей исходников и проверить заново.

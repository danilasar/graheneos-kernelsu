## Ограничения

Образ только для указанной ОС и устройства. Не использовать после OTA без пересборки. Загрузчик остаётся разблокированным. Никаких `fastboot -w`, `flash-all.sh`, factory reset, записи обоих слотов или relock. Сначала `fastboot boot`, после проверки и разрешения пользователя — только активный `boot`.

Комплект экспериментальный: полный Linux MTE/SELinux/syscall код не ослаблялся; обязательная проверка подписи модулей сохранена. APK — отладочный arm64 менеджер с нестандартным PRCTL-транспортом, не официальный APK. Закрытые ключи не публикуются.
